Delayed Approvals Report
This report shows a list of all records that have been awaiting approval for longer than a selected number of days. The results will return a table containing a hyperlink to the individual records, Component, Status, Days Awaiting Approval, Assigned Office, and Requirements Title. Once the report is run the criteria can be updated by clicking on the "Show Filters" button, changing the desired criteria, and clicking the "Filter Report" button. Clicking "Home" or the 4SITE Icon will return you to the Dashboard.

Filters

All filter fields are optional. Use commas for multiple values.
