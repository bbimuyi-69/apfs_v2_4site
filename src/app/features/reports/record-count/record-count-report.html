Record Count Report
This report counts and lists records based on several criteria. If filtering on a given time period only records with histories within the time period will be listed. Histories are created when a record is created, assigned, released, approved, or rejected. This report can also be filtered to users, components, offices, and record status. If none of the filter criteria are selected, the report will return results based on all records in 4SITE. The results will return a table containing a hyperlink to the individual records, the Component, Dollar Range and the Requirements Title. Once the report is run the criteria can be updated by clicking on the "Show Filters" button, changing the desired criteria, and clicking the "Filter Report" button.
